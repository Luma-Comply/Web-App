# Git Secrets Protection

This repository has git-secrets installed to prevent accidental commits of sensitive data.

## Protected Patterns:
- Anthropic API keys (sk-ant-*)
- Supabase secret keys (sb_secret_*)
- Supabase publishable keys (sb_publishable_*)
- Stripe keys (sk_live_*, sk_test_*)
- Resend API keys (re_*)
- Stripe webhook secrets (whsec_*)
- JWT tokens (eyJ*)
- AWS credentials

## What This Means:
- You CANNOT commit files containing these patterns
- Git will block the commit and show an error
- This prevents secrets from ever entering git history

## If You Get Blocked:
1. Remove the secret from the file
2. Verify the secret is in .env.local (which is gitignored)
3. Try committing again
