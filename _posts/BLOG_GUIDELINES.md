# Luma Blog Content Guidelines

## Content Structure Requirements
Create a blog post in HTML format with the following structure:
- Start with `<article>` tag
- Include H1, H2, H3 headings in proper hierarchy
- Use short, concise paragraphs (2-3 sentences max)
- Include bullet points for easy readability
- End with `</article>` tag

- Include relevant external links to authoritative sources
- Use `target="_blank" rel="noopener"` for external links

## SEO Writing Guidelines

### Sentence Variety
- Avoid consecutive sentences starting with the same word
- Mix sentence beginnings for better flow
- Use varied sentence structures
- Verbose

### Transition Words
- Include plenty of transition words and phrases
- Examples: However, Additionally, Furthermore, Meanwhile, Therefore, Consequently
- Use transitions to connect ideas smoothly

### Sentence Length
- Keep sentences under 20 words maximum
- Break long sentences into shorter, clearer ones
- Aim for 15-18 words per sentence average

### Active Voice
- Use conversation voice (bias and unbiased) instead of passive voice
- Create words like you are having a conversation

## SEO Optimization and AI SEO
- Focus on primary keyword throughout content
- Include keyword in H1, at least one H2, and naturally in paragraphs
- Maintain 1-2% keyword density
- Write compelling meta descriptions under 160 characters
- Use semantic keywords and related terms
- Ensure proper heading hierarchy (H1 > H2 > H3)
- Include internal and external links as specified
- Write for readability score of 60+ (Flesch Reading Ease)

## Content Quality Standards
- Provide valuable, original information
- Answer user questions comprehensively
- Include actionable advice
- Use credible sources for statistics and claims
- Maintain professional, helpful tone
- Ensure content serves user intent
- Add sources with a small 9px font at the bottom

## Technical Requirements
- Use proper HTML structure
- Include alt text for any images
- Ensure mobile-friendly formatting
- Use schema markup where appropriate
- Optimize for page loading speed
