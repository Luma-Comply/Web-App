# Luma

AI-powered medical necessity documentation for biologics prior authorizations.

## What is Luma?

Luma helps healthcare providers create audit-proof documentation for prior authorizations. Our HIPAA-compliant platform uses AI to generate compliant medical necessity letters in seconds, not hours.

## Key Features

- **HIPAA Safe Harbor Compliant** - No PHI required; uses only patient name + clinical data
- **AI-Powered Generation** - Creates payer-specific documentation instantly
- **Export Options** - Download as Word, PDF, or copy to clipboard
- **Multi-Payer Support** - Medicare, Medicaid, and commercial insurers

## Getting Started

1. Copy `.env.example` to `.env.local` and fill in your credentials
2. Run `npm install`
3. Run `npm run dev`
4. Open http://localhost:3000

See `.env.example` for required environment variables.
